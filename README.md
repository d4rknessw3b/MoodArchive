# MoodArchive 📝✨

**MoodArchive** — это современное мобильное Android-приложение на Kotlin для ведения личного дневника эмоций и воспоминаний. Приложение позволяет удобно фиксировать свое состояние, делиться мыслями текстом или голосом, а также сохранять памятные моменты с помощью фото и видео.

## Основные возможности 🚀

- **Трекинг эмоций**: Запись своего настроения с использованием различных эмодзи и цветового кодирования.
- **Мультимедиа вложения**: Поддержка прикрепления фотографий, видео, файлов, а также встроенный диктофон для создания голосовых заметок.
- **Встроенный аудиоплеер**: Прослушивание записанных голосовых заметок прямо в приложении с визуализацией прогресса.
- **Офлайн-доступ и Синхронизация**: Все записи надежно хранятся локально. Фоновая синхронизация с облаком выполняется через `WorkManager`.
- **Безопасность**: Защита личных записей с помощью ПИН-кода или биометрии (отпечаток пальца/Face ID).
- **Экспорт данных**: Удобный экспорт ваших записей в форматы **PDF** или **Markdown** для резервного копирования или шеринга.
- **Поиск и Фильтрация**: Быстрый поиск по тексту записей и фильтрация по эмоциям.

## Технологический стек 🛠️

- **Язык**: Kotlin
- **UI Framework**: Jetpack Compose (Material Design 3)
- **Архитектура**: Clean Architecture (Presentation, Domain, Data) + MVVM
- **Локальная БД**: Room
- **Асинхронность**: Coroutines & Flow
- **Dependency Injection**: Dagger Hilt
- **Фоновые задачи**: WorkManager
- **Работа с медиа**: MediaRecorder (аудио), Coil (асинхронная загрузка изображений)
- **Управление разрешениями**: Accompanist Permissions

## Требования 📱
- Минимальная версия Android: 8.0 (API 26)
- Android Studio Koala (или новее)
- Установленный JDK 17+

## Структура проекта 📂
Проект разбит на четкие слои (Clean Architecture):
- `presentation/` — UI слой на основе Jetpack Compose, ViewModels.
- `domain/` — бизнес-логика, модели, интерфейсы репозиториев.
- `data/` — реализация репозиториев, локальная база данных (Room).
- `worker/` — логика фоновой синхронизации (WorkManager).
- `di/` — модули Dagger Hilt.
- `util/` — вспомогательные классы (например, для экспорта в PDF/Markdown).

## Как запустить проект ▶️

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/d4rknessw3b/MoodArchive.git
   ```
2. Откройте проект в **Android Studio**.
3. Дождитесь синхронизации Gradle.
4. Выберите эмулятор или подключенное Android-устройство.
5. Нажмите **Run** (Shift + F10).
